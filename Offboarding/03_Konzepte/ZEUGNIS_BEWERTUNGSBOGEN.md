# Zeugnis-Bewertungsbogen fuer Vorgesetzte

**Erstellt:** 2026-03-27
**Kontext:** CREDO HR-Portal -- Offboarding-Modul fuer Bildungseinrichtungen
**Quellen:** SS 109 GewO, BAG-Rechtsprechung, Haufe Zeugnis Manager, arbeitszeugnis.de, Karrierebibel u.v.m.

---

## Konzept

Der Vorgesetzte vergibt einfach **Schulnoten (1-6)** per Klick. Das System uebersetzt diese automatisch in rechtssichere Zeugnisformulierungen. HR prueft und finalisiert.

---

## Rechtliche Grundlagen

### Pflichtbestandteile qualifiziertes Arbeitszeugnis (SS 109 GewO)
1. Ueberschrift
2. Einleitung (Name, Geburtsdatum, Eintrittsdatum, Position)
3. Unternehmensbeschreibung
4. Taetigkeitsbeschreibung
5. **Leistungsbeurteilung** (Fachkompetenz, Arbeitsbereitschaft, Arbeitsweise, Arbeitserfolg)
6. **Fuehrungsleistung** (nur bei Fuehrungskraeften)
7. **Verhaltensbeurteilung** (Vorgesetzte, Kollegen, Externe)
8. **Gesamtbeurteilung** (Zufriedenheitsformel)
9. Schlussformel (Bedauern, Dank, Zukunftswuensche)
10. Datum und Unterschrift

### BAG-Rechtsprechung
- **Note 3 ("befriedigend") ist Durchschnitt** (BAG, 18.11.2014, 9 AZR 584/13)
- Bis Note 3: Beweislast beim **Arbeitgeber**
- Ab Note 2 oder besser: Beweislast beim **Arbeitnehmer**
- Kein gesetzlicher Anspruch auf Schlussformel, aber Fehlen wird negativ gewertet

## Zufriedenheitsskala (Gesamtbeurteilung)

| Note | Formulierung |
|------|-------------|
| **1** (sehr gut) | "...stets zu unserer **vollsten** Zufriedenheit" |
| **2** (gut) | "...stets zu unserer **vollen** Zufriedenheit" |
| **3** (befriedigend) | "...zu unserer **vollen** Zufriedenheit" |
| **4** (ausreichend) | "...zu unserer Zufriedenheit" |
| **5** (mangelhaft) | "...im Grossen und Ganzen zu unserer Zufriedenheit" |
| **6** (ungenuegend) | "...hat sich bemuet, den Anforderungen gerecht zu werden" |

## Workflow: Magic-Link-Flow

```
1. HR legt Zeugnisvorgang an → waehlt Berufsgruppe
2. System generiert Magic-Link (14 Tage gueltig)
3. E-Mail an Vorgesetzten
4. Vorgesetzter vergibt Noten (1-6) per Klick + Freitext
5. System berechnet Gesamtnote + generiert Zeugnisentwurf
6. HR erhaelt Benachrichtigung → prueft und passt an
7. Freigabe-Link an Vorgesetzten
8. Vorgesetzter gibt frei oder kommentiert
9. Finalisierung → Druck/Versand → Archivierung
```

### Sonderregeln
- Bei Abweichung > 2 Notenstufen zwischen Kategorien: HR-Warnung
- Bei Gesamtnote >= 4.0: Hinweis auf besondere rechtliche Pruefung
- Reihenfolge Sozialverhalten immer: Vorgesetzte → Kollegen → Externe

## Datenmodell (Prisma-Sketch)

```prisma
model CertificateProcess {
  id                String              @id @default(uuid())
  offboardingId     String
  offboarding       OffboardingProcess  @relation(fields: [offboardingId], references: [id])

  roleVariant       RoleVariant
  certificateType   CertificateType     // EINFACH, QUALIFIZIERT
  status            CertificateStatus   @default(PENDING)

  // Magic Links
  assessmentToken       String?     @unique
  assessmentTokenExp    DateTime?
  approvalToken         String?     @unique
  approvalTokenExp      DateTime?

  // Bewertungen (JSON: [{criterionId, note, category}])
  assessmentsJson       Json?
  freeTextsJson         Json?

  // Berechnete Noten
  overallGrade          Float?
  overallGradeRounded   Int?
  categoryGradesJson    Json?       // [{category, avgGrade, weightedGrade}]

  // Entwurf
  draftContent          String?     // Generierter Zeugnis-Text
  draftVersion          Int         @default(0)
  supervisorComment     String?
  hrComment             String?

  // Tracking
  assessedAt            DateTime?
  assessedById          String?     // Vorgesetzter
  draftCreatedAt        DateTime?
  approvedAt            DateTime?
  sentAt                DateTime?

  createdAt             DateTime    @default(now())
  updatedAt             DateTime    @updatedAt

  @@map("certificate_processes")
}

model CertificateFormulation {
  id              String          @id @default(uuid())
  category        String          // z.B. "Gesamtbeurteilung"
  roleVariant     RoleVariant?    // null = allgemeingueltig
  grade           Int             // 1-6
  formulation     String
  isActive        Boolean         @default(true)

  @@map("certificate_formulations")
}
```
