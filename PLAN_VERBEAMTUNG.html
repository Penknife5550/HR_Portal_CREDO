1 Vision: Multi-Prozess HR-Portal
Das HR-Portal wird von einer reinen Onboarding-Lösung zu einer Multi-Prozess-Plattform erweitert. Jeder HR-Prozess (Onboarding, Verbeamtung, später: Offboarding, Versetzung, etc.) wird als eigener Prozesstyp abgebildet – mit eigenen Phasen, Checklisten und Formularen.
📄 Heute: Nur Onboarding
  • 1 Prozesstyp (STANDARD/BEAMTER)
  • Fragebogen für neuen Mitarbeiter
  • Vorgesetzten-Modalitäten
  • Statische Checkliste
  • CSV/JSON Export
🌟 Zukunft: Multi-Prozess
  • Onboarding (wie bisher)
  • Verbeamtung (PSI) – NEU
  • Offboarding (später)
  • Versetzung (später)
  • Vertragsverlängerung (später)

4 Der Verbeamtungsprozess im HR-Portal
So würde der komplette PSI-Prozess (5 Phasen) im HR-Portal ablaufen – von der Antragstellung bis zur Übernahme auf Lebenszeit.

Phase 1: Antrag & Beurteilung T-6 Monate

Schulleitung startet den Prozess im HR-Portal. Die Lehrkraft wird zugeordnet.

Was passiert im Tool:
  • HR/SL erstellt neuen Verbeamtungsvorgang (wie bei Onboarding: Lehrkraft auswählen, Schule zuordnen)
  • Checkliste Phase 1 wird automatisch generiert (Antrag, Unterrichtsbesuch, Beurteilung, Beiratsentscheidung)
  • Supervisor-Link wird an Schulleitung gesendet → SL füllt die Beurteilung digital aus
  • Beurteilungsbogen (Kriterien: Andachten, Engagement, Belastbarkeit, etc.) als Formular
  • Beiratsentscheidung wird dokumentiert (Positiv / Negativ / Aufgeschoben)

Phase 2: Verwaltungsvorgang starten T-3 Monate

Nach positiver Beiratsentscheidung startet die Personalverwaltung.

Was passiert im Tool:
  • Automatischer Webhook/E-Mail an Personalabteilung: „Verbeamtung genehmigt – Verwaltungsvorgang starten“
  • Checkliste Phase 2 wird freigeschaltet (Info an PA, Beurteilung einreichen)
  • Dokument-Upload: Unterschriebene Beurteilung der SL
  • Status wechselt automatisch bei Abschluss aller Punkte

Phase 3: Personaladministration Die umfangreichste Phase

Alle Verwaltungsschritte: Vertrag, BR, Versicherung, RV-Befreiung, LOGA.

Was passiert im Tool (8 Kategorien):
KategorieChecklisten-Punkte im Tool
3.1 VertragsunterlagenAmtsärztl. Zeugnis anfordern, Vertrag auf Probe erstellen, Stufenberechnung
3.2 BetriebsratUnterlagen an BR senden, Antwort dokumentieren (mit Frist-Warnung)
3.3 VersicherungKK-Privatversicherung Info, Beihilfe-Antrag, Meldung Beihilfestelle
3.4 RentenversicherungRV-Befreiungsantrag + Gewährleistungsentscheidung MSB beilegen
3.5 AbrechnungVertragsende Angestelltenverhältnis, Mehrarbeit, Personalbogen Beamte
3.6 LOGA-UmstellungTransfer, neue Pers.-Nr., Kostenstelle, Pensionsrückstellungen
3.7 KommunikationInfo Sekretariat, Info UNTIS
3.8 FördervereinMitgliedschaft prüfen/beantragen
⚠ Automatische Fristen-Warnungen Das Tool warnt automatisch wenn: Amtsarztzeugnis älter als 3 Monate wird, BR-Frist abläuft, oder Gewährleistungsentscheidung fehlt.

Phase 4: Probezeit 3 Jahre

Begleitende Beurteilungen und Unterrichtsbesuche während der Probezeit.

Was passiert im Tool:
  • Automatische Erinnerungen für die 3 Pflichtbeurteilungen (via n8n Webhook)
  • 2. Unterrichtsbesuch nach 1 Jahr → SL-Link für Beurteilung
  • 3. Unterrichtsbesuch zum Probezeit-Ende → SL-Link für Beurteilung + Geistliche Stellungnahme
  • Alle Beurteilungen als Dokument hochladbar
  • Fortschrittsanzeige: 3 von 3 Beurteilungen abgeschlossen

Phase 5: Übernahme auf Lebenszeit T-3 Monate vor Probezeit-Ende

Finale Phase: Beiratsentscheidung, neues Zeugnis, Vertrag auf Lebenszeit.

Was passiert im Tool:
  • Tool berechnet automatisch: Probezeit endet am [Datum] → Phase 5 muss starten am [Datum-3 Monate]
  • Beiratsentscheidung dokumentieren (Positiv / Negativ / Verlängerung)
  • Neues Amtsarztzeugnis anfordern (⚠ altes reicht nicht!)
  • Gespräch Vorstand ↔ PSI dokumentieren
  • Vertrag auf Lebenszeit + BR-Anhörung
  • Vorgang abgeschlossen → Export möglich

9 Zusammenfassung
Das HR-Portal wird zur zentralen Plattform für alle Personal-Prozesse. Der Verbeamtungsprozess nutzt die gleiche Infrastruktur wie das Onboarding (Webhooks, E-Mail-Vorlagen, Checklisten, Dokumente, Magic-Links), erweitert sie aber um Phasen-Management, Beurteilungsformulare und automatische Fristen-Warnungen.
Vorgesetzten-Link funktioniert genau wie beim Onboarding. Die Schulleitung erhält einen Magic-Link, füllt die Beurteilung digital aus, und HR wird automatisch benachrichtigt. Alle 3 Pflichtbeurteilungen laufen über diesen Mechanismus.
Fristen sind kritisch beim PSI-Prozess. Das Tool berechnet automatisch alle relevanten Termine (T-6, T-3, Probezeit-Ende, Amtsarztzeugnis-Ablauf) und warnt per E-Mail, bevor Fristen ablaufen.

Bereit zur Umsetzung?

Alle bestehenden Systeme (Webhooks, SMTP, E-Mail-Vorlagen, Mandanten) können wiederverwendet werden.
Der Verbeamtungsprozess ist die erste Erweiterung – weitere Prozesse folgen dem gleichen Muster.
